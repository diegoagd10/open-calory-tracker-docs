# Open Calorie Tracker · OAuth integration guide

This public, static site explains how to register an OAuth client, ask a Food Log owner for `daily-log:read`, and call the read-only Daily Food Log API.

Published at https://diegoagd10.github.io/open-calory-tracker-docs/.

The site has no analytics, forms, or external assets. Replace the example instance URL with the URL of your own Open Calorie Tracker installation.
